# Coach Chris

An AI version of Chris to ask when you get stuck with AVS: installing, making a video, filming, or a strange error.

Set it up once, about two minutes. Both files are in your AVS folder: tell Claude "open my Coach Chris folder" to see them.
1. At claude.ai, open Projects and create a new project called "Coach Chris".
2. Open "Set project instructions" and paste in everything from `Coach-Chris-Instructions.txt`.
3. Add `AVS-Guide.md` to the project's files.
4. Ask it anything, like "my install stopped partway" or "which style should I use for an ad?"

After an AVS update, replace `AVS-Guide.md` in the project with the new one from the same folder.

It answers from the AVS guide. It's set up to say so when the guide doesn't cover something, and to send you to the AdCamp community for anything still stuck after two tries.
